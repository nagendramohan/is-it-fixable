# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, welcoming, and constructive. Harassment or exclusionary behavior of any kind
is not tolerated. We want contributing here to be a good experience for everyone, especially first-time
contributors.

Report concerns to the maintainer via a GitHub issue or the contact listed on the maintainer's profile.
The full text of the Contributor Covenant 2.1 applies and can be read at the link above.
